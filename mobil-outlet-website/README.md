# Mobil Outlet — website concept

A responsive, Swedish-language one-page website concept for Mobil Outlet in Marieberg Galleria, Örebro. Built with plain HTML, CSS and JavaScript. No build tools or server required.

## Preview locally

Open `index.html` in a browser.

## Included

- Responsive layout with mobile navigation
- Service cards for repairs, refurbished phones, selling a phone and accessories
- Separate `salj.html`, `salj.js` and `salj.css` sell valuation flow
- Separate `kop.html`, `kop.js` and `kop.css` used-phone catalogue with search and filters
- Separate `tips.html`, `tips.js` and `tips.css` step-by-step mobile help guides
- Links to the existing Mobil Outlet site for the shop and accessory/relevant pages
- Repair enquiry form which opens the user's email client with a pre-filled message
- Store address, phone number, email and opening hours
- Accessible focus states, labels and reduced-motion support

## Before publishing

- Confirm the wording, logos, visual identity and all business details with Mobil Outlet.
- The repair form is a front-end demo only; it does not send/store submissions itself. For a production site, connect a secure form backend or booking service.
- The sell valuation is a front-end estimate only. Replace the sample price table with current buying prices and connect a secure backend before launch.
- Check current inventory, repair prices, warranty details, privacy policy and purchase terms before making sales claims.
- Use approved original store/product photographs and confirm image rights.
- Configure analytics, cookie consent and SEO/social preview metadata if required.
